# Nava Snake 🐍

브라우저에서 바로 즐기는 클래식 스네이크 게임입니다.

## 실행 방법

정적 파일이므로 간단한 로컬 서버로 실행하면 됩니다.

```bash
python3 -m http.server 8000
```

이후 `http://localhost:8000` 접속.

## 조작

- 방향키 (↑ ↓ ← →) 또는 `W A S D`
- 화면의 방향 버튼 (모바일 지원)
- 화면 스와이프
- `Space`: 일시정지 / 재개
- 속도(느림/보통/빠름/매우 빠름) 선택 가능

## 기능

- 최고 점수는 `localStorage`에 저장되어 다음 방문 때도 유지됩니다.
- 다크/라이트 모드 자동 대응.
- 데스크톱과 모바일 모두 반응형으로 동작합니다.
